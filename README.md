# WEREWOLF — Moderator Game Assistant

A React + Vite + Tailwind CSS web app for running a Werewolf game from one moderator device.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Game state is stored in browser localStorage.
- The supplied game logic and UI are preserved in `src/App.jsx`.
- The project is configured for deployment on common Vite hosts such as Vercel, Netlify, or GitHub Pages.
